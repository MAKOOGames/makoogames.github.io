# MAKOO Games | Official Studio Profile

The digital gateway to **MAKOO Games**, an independent game development studio dedicated to creating immersive and visually striking interactive experiences.

## 🕹️ About the Project
This landing page serves as our central hub—a high-performance, minimalist interface designed to connect our players with our social ecosystems and storefronts. 

## 🚀 Technical Architecture
Built with a focus on speed and visual impact, the site features:
* **Custom Motion Graphics:** An infinite-panning panoramic engine designed to showcase studio concept art.
* **Modernized Social Stack:** Integrated support for next-gen social platforms including **X** and **Bluesky** using SVG-based iconography.
* **Responsive Core:** A mobile-first CSS architecture that ensures a seamless experience from 4K desktops to handheld devices.
* **Optimized Assets:** High-fidelity branding and background assets optimized for fast load times without sacrificing visual quality.

## 📁 Directory Setup
* `index.html`: The core site structure.
* `main.css`: Our custom stylesheet containing the animation logic and studio UI.
* `Logo.png`: Official MAKOO Games branding.
* `bg.jpg`: Studio panoramic environmental art.
